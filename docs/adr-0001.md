# ADR-0001 : petit socle Python et sources immuables

Statut : accepté pour le prototype (2026-10-11).

## Décision

Utiliser Python 3.11+ (bibliothèque standard) pour l'ingestion RONI, un stockage de snapshots sur disque, une API HTTP locale en lecture seule et une interface HTML/CSS/JS sans compilation.

## Motifs

- Contrôle du format NOAA et reproductibilité.
- Zéro dépendance externe et surface d'attaque réduite au stade expérimental.
- Tests simples, exécution locale sans Docker et sans configuration du serveur SILLO.
- Passage futur vers FastAPI/PostgreSQL/PostGIS seulement lorsqu'il répond à un besoin prouvé.

## Limites

- Un seul processus et un seul rédacteur de données.
- Pas d'identités, de recherche géographique, de file de messages ni de diffusion d'alertes.
- Le serveur de développement n'est ni durci pour Internet, ni authentifié.
- Aucune ingestion automatique en arrière-plan.
